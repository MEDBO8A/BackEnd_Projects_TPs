# Atelier 5 — Persistance des données avec Prisma et MySQL


## 56. Exercice 1 — Comprendre Prisma

1. Quelle est la différence entre : MySQL et : Prisma
    - MySQL : Le moteur qui stocke physiquement les données.
    - Prisma : L'outil (ORM) qui fait le pont entre votre code et la base de données.
2. Quel est le rôle de : schema.prisma ?
    - Le fichier de configuration central pour définir la connexion à la base de données et la structure de vos tables.
3. Quel est le rôle de : Prisma Client ?
    - La bibliothèque générée automatiquement pour interagir facilement avec la base de données
4. Quel est le rôle d'une migration ?
    - Un script qui enregistre et applique les modifications du schémas cree dans le code
